# Amended WP3 protocol: new frozen deployment model

**Amendment date:** 2026-10-20. **Status:** specified before any external model prediction or scoring. This amendment supersedes the previous WP3 no-refit restriction **with the user's explicit authorization**. It does not recover the missing Phase 3 checkpoints and does not alter the historical nested-CV results. The final claim must be “external evaluation of a newly frozen deployment model.”

## Training-only decisions

The only fitting data are the 1,513 original standardized BACE rows. The eligible ChEMBL cohort is not used for model training, calibration, feature scaling, parameter selection, or fusion fitting. The existing Phase 3 repeat-1 outer-test predictions provide one scaffold-held-out RF and ChemBERTa probability per original molecule and seed. Average the three seed probabilities per molecule. For the final deployment base experts, use three fixed seeds (11, 22, 33) and average their probabilities. RF uses radius-2, 2,048-bit chiral Morgan fingerprints, 200 trees, `balanced_subsample`, depth 24, minimum leaf 1, and `sqrt` max features. The RF depth/leaf setting is the modal Phase 3 inner-CV choice; the frozen ChemBERTa head uses the modal inner-CV setting (64 hidden units, dropout 0.1, learning rate 0.0003, weight decay 0.0001) and 80 full-data epochs. ChemBERTa-77M-MLM at the recorded revision remains frozen and uses masked-mean token pooling; a StandardScaler is fitted on the original training embeddings for each seed. These choices are fixed here without consulting external model performance.

For each original molecule, generate **cross-fitted calibrated training inputs** by fitting one Platt calibrator per expert on the other four repeat-1 outer folds' averaged raw probabilities and applying it to the held-out fold. Fit the two *deployment* Platt calibrators on all 1,513 cross-fitted raw probabilities. The external predictions use those deployment calibrators and the mean of each expert's three full-data seed models. The gate is trained only on the cross-fitted calibrated original-data probabilities. Its max Tanimoto feature for each held-out molecule is computed against the four training folds, never against the held-out fold or the molecule itself. External max Tanimoto uses all original training molecules. The entropy difference is `H(ChemBERTa) - H(RF)`. Feature mean and population SD are fitted on the original gate-training rows.

C1 minimizes training Brier score over `0 <= alpha <= 1` on the gate-training probabilities. D2 is the regularized shrunk gate already defined in Phase 5: `alpha(x) = (1-lambda)*alpha_C1 + lambda*sigmoid(beta0 + beta1*z(similarity) + beta2*z(entropy_difference))`, with the fixed Phase 5 penalties and optimizer. Neither weight nor gate can be updated from external outcomes. A high-quality external result would validate **this newly deployed recipe**, not the exact historical fold-specific D2 instances.

## Freeze and one-time analysis

Before loading external labels into evaluation code, save and hash all RF checkpoints, MLP state dictionaries, scalers, the two deployment Platt calibrators, C1 weight, D2 coefficients and feature scaling, frozen encoder revision, training input, OOF table, cohort lock and CSV, config, and scoring script. Record the Git HEAD plus file hashes because this checkout contains uncommitted research artifacts. The scoring command must verify every hash and refuse to run if output already exists. It will not fit any component.

Score both assays with the identical frozen pipeline but keep them **separate**. `CHEMBL5736880` is the single primary external cohort. `CHEMBL5734173` is a secondary, older-source sensitivity cohort and cannot be pooled post hoc. All four methods (calibrated RF, calibrated ChemBERTa, C1, D2) use exactly the same eligible molecules within each assay.

Primary discrimination metric: sklearn average precision (AP); report prevalence with every AP. Key probability metric: Brier. Also report ROC-AUC, clipped log loss, Precision@Top 5% and 10%, enrichment factors, and fixed-bin reliability plots. Top-k uses `ceil(fraction*n)`, minimum one, descending probability and then ascending `assay_chembl_id|standardized_inchikey` for exact ranking ties. `0.5` is descriptive only; no external threshold selection.

The primary comparison is paired `AP(D2)-AP(C1)`. Resample the primary cohort's distinct scaffolds with replacement 10,000 times (seed 20261020), copying all molecules of each selected scaffold with multiplicity and using identical sampled indices for both models. Redraw a single-class resample and count it. Stop after 100,000 attempts; fewer than 9,500 valid replicates means no informative interval. Report the percentile 95% CI, accepted/rejected counts, and number of scaffolds. Fewer than 20 primary scaffolds or CI width over 0.10 is prespecified as **inconclusive** for the support decision. Do not switch to a molecule bootstrap.

Leave-one-scaffold-out AP differences check concentration of benefit: to count as supportive, all leave-one-out differences must remain positive and at least 50% of the full-cohort AP gain. Because the primary cohort has just one patent/assay source, assay-source leave-one-out robustness cannot be estimated. The secondary assay provides a distinct-source sensitivity check, not a replacement primary analysis; a supportive result also requires its D2-C1 AP difference to be positive and at least 50% of the primary gain. Even if that holds, the final claim remains limited to these two assay sources. A supportive gate result additionally requires primary AP improvement >=0.01, 95% CI lower bound >0, and D2 Brier minus C1 Brier <=0.003. If the interval is uninformative, call the comparison inconclusive. Otherwise retain C1 and describe the gate as unsupported for practical deployment. Any change motivated by external results requires a further independent set.

Reliability diagrams use the ten fixed probability bins `[0,0.1),...,[0.9,1]` with mean predicted probability, observed active fraction and denominators. Similarity strata use fixed edges `<0.4`, `0.4–<0.6`, `0.6–<0.8`, `>=0.8`; assay and similarity stratification are **exploratory**, with molecule and positive counts and no claims from single-class strata.
